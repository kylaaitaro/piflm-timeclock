# PIFLM Time Clock Web App

## Add your Google Form link
Open `config.js` and replace `PASTE_YOUR_GOOGLE_FORM_LINK_HERE` with your published Google Form URL. Keep the quotation marks.

## Publish with GitHub Pages
1. Sign in to GitHub.
2. Create a new **public** repository named `piflm-timeclock`.
3. Upload every file from this folder.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then save.
7. Wait a few minutes for the site address.

Your address will look like:
`https://YOUR-USERNAME.github.io/piflm-timeclock/`

## Add to iPhone
1. Open the published address in Safari.
2. Tap Share.
3. Tap **Add to Home Screen**.
4. Tap **Add**.

The PIFLM custom icon will appear automatically.

## Important
This page does not store payroll data. It opens your existing Google Form.
